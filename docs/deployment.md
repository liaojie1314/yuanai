# 部署指南

面向自托管：服务器选型、推荐配置、域名与 HTTPS、以及本项目特有的部署坑。

开发环境启动见 [开发运行指南](dev-guide.md)，发版流程见 [发版与 CI/CD](release.md)。

## 1. 服务器选型：国内还是国外

两条路径都可行，**取决于你的用户在哪、用哪家模型、域名注册在哪**。先用下表定位，
再看对应小节。

### 1.1 决策表

| 你的情况                                               | 建议     |
| ------------------------------------------------------ | -------- |
| 用户主要在中国大陆，且只用国内模型供应商               | **国内** |
| 需要直连 OpenAI / Anthropic Claude                     | **国外** |
| 域名注册在境外注册商（NameSilo、GoDaddy 等）且不想转移 | **国外** |
| 需要 SearXNG 联网搜索抓取境外搜索引擎                  | **国外** |
| 面向境外用户，或纯个人自用                             | **国外** |
| 有合规要求必须数据留在境内                             | **国内** |

三个关键差异：

| 维度            | 国内服务器                                  | 国外服务器                    |
| --------------- | ------------------------------------------- | ----------------------------- |
| ICP 备案        | 对外开放 80/443 **必须备案**，周期约 1-3 周 | 不需要                        |
| OpenAI / Claude | 无法直连，只能用国内模型                    | 可直连                        |
| 大陆用户延迟    | 最优（通常 <30ms）                          | 30ms（香港）至 250ms+（欧美） |

### 1.2 国内部署路径

**备案是前置条件，先办备案再谈其他。**

备案硬性要求：

1. **域名注册商必须经工信部认证**（阿里云、腾讯云、华为云、西部数码等）。
   境外注册商（NameSilo、GoDaddy、Namecheap 等）的域名**无法直接备案**，
   必须先转入国内注册商；
2. 域名后缀需在工信部批准列表内（`.com` / `.cn` / `.net` 等常见后缀可以，部分新顶级域不行）；
3. 服务器必须购买国内厂商且时长 ≥3 个月，并申请备案服务号；
4. 需实名认证 + 人脸/拍照核验，周期约 1-3 周；
5. 备案通过后 30 日内还需完成**公安备案**。

模型供应商：DeepSeek、通义千问、智谱 GLM、Moonshot、百川等均可直连，
按 [AI 大模型接入指南](ai-providers.md) 配置即可。

常见厂商与价格（4 vCPU / 8 GB 档，月付粗略区间）：

| 厂商                       | 价格区间    | 说明                               |
| -------------------------- | ----------- | ---------------------------------- |
| 阿里云 / 腾讯云 / 华为云   | ¥200-500/月 | 新用户首年有大幅折扣，续费价高很多 |
| UCloud / 京东云 / 天翼云   | ¥150-400/月 | 价格略低                           |
| 轻量应用服务器（各家均有） | ¥60-150/月  | 含固定流量包，小规模部署性价比高   |

> 国内带宽按 Mbps 计费且单价高，**优先选带固定流量包的轻量应用服务器**；
> 本项目有 MinIO 对象存储与媒体文件，流量消耗不低。
> 大陆境内 CDN 与对象存储（OSS/COS）单价便宜，可把静态资源与附件托管过去降低回源带宽。

### 1.3 国外部署路径

无需备案，域名加 A 记录即可对外服务；可直连 OpenAI / Claude；SearXNG 可正常抓取。

地区选择：

| 地区                 | 到大陆延迟 | 适用                                     |
| -------------------- | ---------- | ---------------------------------------- |
| 香港                 | ~30-50ms   | 用户主要在大陆时延迟最优；廉价套餐常限速 |
| 日本 / 新加坡 / 韩国 | ~60-120ms  | 延迟与价格较均衡，线路比香港稳定         |
| 美西                 | ~150-200ms | 价格低，适合纯自用或海外用户             |
| 欧洲（德国、芬兰）   | ~250ms+    | 单价最低，但对大陆访问体验差             |

支付方式（大陆用户）：

| 厂商                      | 支付方式                                              |
| ------------------------- | ----------------------------------------------------- |
| 阿里云 / 腾讯云**国际版** | 支付宝、微信，中文界面与中文客服，开通最省心          |
| Vultr、DigitalOcean       | 支付宝、PayPal、信用卡                                |
| Hetzner、Contabo          | 信用卡 / PayPal（Hetzner 对新账号审核较严，偶有拒开） |
| AWS / GCP / Azure         | 基本必须 Visa/MasterCard，支付宝一般不可用            |

价格（4 vCPU / 8 GB 档，月付粗略区间）：

| 区域 | 代表机型                                   | 价格区间    | 取舍                    |
| ---- | ------------------------------------------ | ----------- | ----------------------- |
| 欧洲 | Hetzner CPX31（4C/8G/160GB，含 20TB 流量） | ≈ €16/月    | 最划算，但到大陆 250ms+ |
| 美国 | Vultr / DigitalOcean / Linode              | ≈ $40-48/月 | 均衡，含 3-5TB 流量     |
| 亚太 | 阿里云/腾讯云国际版香港、Vultr 东京        | ≈ $48-80/月 | 延迟最低，价格最高      |

**两个容易踩的坑：**

1. **国内厂商国际版的带宽是隐藏大头。** 阿里云/腾讯云香港节点按**固定带宽**计费，
   5 Mbps 就可能数百元/月。Hetzner 含 20TB、Vultr 含 3-5TB 流量反而总价更低 ——
   支付最方便的厂商往往总价最贵。
2. **超低价套餐要警惕超售。** Contabo（€7-9/月）、RackNerd 年付特价（$50-70/**年**）
   单价极低，但超售严重、磁盘 IO 波动大，适合练手，不适合正式对外服务。

> 以上价格随时变动，仅为量级参考，下单前请到官网核实现价。

## 2. 推荐配置

### 2.1 本项目（yuanai）常驻服务

一台机器需要同时跑：

| 组件                                                  | 约占内存   |
| ----------------------------------------------------- | ---------- |
| PostgreSQL 16                                         | 0.5-1 GB   |
| Redis 7                                               | ~256 MB    |
| MinIO（对象存储）                                     | ~512 MB    |
| SearXNG                                               | 256-512 MB |
| FastAPI 后端（uvicorn）                               | 0.5-1 GB   |
| agent_worker + recovery_worker + automation_scheduler | ~1 GB      |
| Next.js Web（production）                             | 0.5-1 GB   |
| 系统与 Docker 自身                                    | ~1 GB      |

合计常驻约 **4.5-6 GB**。

### 2.2 配置档位

| 档位              | 场景                                  | 配置                                  |
| ----------------- | ------------------------------------- | ------------------------------------- |
| 最小可跑          | 仅 yuanai，自用/演示，AI 全走外部 API | 2 vCPU / 4 GB / 60 GB SSD（会比较紧） |
| **推荐起步**      | yuanai 生产，小规模真实用户           | **4 vCPU / 8 GB / 100-160 GB NVMe**   |
| 两个项目同机      | yuanai + yuanchat 一起部署            | 8 vCPU / 16 GB / 200+ GB NVMe         |
| 本地音乐/媒体生成 | 自托管 MusicGen / ACE-Step            | **另配 GPU 机器**，显存 ≥12-16 GB     |

**磁盘以 MinIO 为大头**：聊天附件、头像、生成的图片/音频都落在对象存储里，按实际用量增长，
起步给 100 GB，预留扩容能力（选支持在线扩盘的厂商）。

### 2.3 两个项目同机时的额外开销

yuanchat 是 Go + PostgreSQL + Redis + MinIO + coturn，若启用阶段二的 Elasticsearch，
JVM 堆至少再吃 2-4 GB，因此两个项目同机**建议直接上 16 GB**。

两点注意：

- **coturn（WebRTC TURN 中继）吃带宽**：音视频通话走中继时按并发路数线性增长，
  需要独立公网 IP 与不限流量（或大流量包）的套餐，别选按流量计费的小包。
- 两个项目**不要共用同一个 PostgreSQL 实例的同一库**；用独立实例或至少独立库 + 独立账号，
  避免迁移互相污染。

### 2.4 GPU 与音乐生成

`docs/media-generation.md` 里的本机 MusicGen 与 ACE-Step 需要 GPU 推理。生产环境二选一：

- **推荐**：改用外部 API 供应商，Web 服务器不需要 GPU；
- 自托管：单独一台 GPU 机器，**不要和 Web/数据库挤同一台** —— 推理会把 CPU 和内存打满，
  拖垮在线对话。低显存机器无法完成 ACE-Step 推理时不要反复重试同一任务。

## 3. 域名与 HTTPS

### 3.1 DNS 解析

无论域名注册在哪家，做法都一样：加一条 A 记录指向服务器公网 IP。

| 注册商                   | 入口                                    |
| ------------------------ | --------------------------------------- |
| 阿里云 / 腾讯云 / 华为云 | 控制台 → 云解析 DNS → 添加记录          |
| NameSilo                 | Manage Domains → 选中域名 → DNS Records |
| GoDaddy / Namecheap      | Domain → DNS / Manage DNS               |

给 `@` 和 `www` 各加一条 A 记录即可。

### 3.2 HTTPS 证书

- **国外部署**：Caddy（自动申请续期，最省事）或 nginx + certbot 申请 Let's Encrypt；
- **国内部署**：同样可用 Let's Encrypt；也可在云厂商控制台申请免费 DV 证书并一键部署到负载均衡。
  **注意备案通过前，80/443 会被阻断，证书签发也会失败**，务必先完成备案。

### 3.3 可选：接入 CDN

- **国外**：Cloudflare 免费版即可（CDN + DDoS 防护 + 免费证书）。
  托管方式为把注册商的 NS 改成 Cloudflare 提供的 NS，SSL/TLS 模式选 **Full (strict)**。
- **国内**：备案后可用阿里云 CDN / 腾讯云 CDN，把静态资源与对象存储附件走 CDN 降低回源带宽。

### ⚠️ 反向代理与 CDN 对 SSE 流式对话的影响

本项目的 AI 回复走 **SSE（Server-Sent Events）**，Agent Run 可能长时间保持连接。
这是部署本项目最容易踩的坑，两类问题：

**1）CDN / 代理层超时与缓冲**

- Cloudflare 橙云代理默认 **100 秒** 响应超时（免费/Pro 版），长任务 SSE 会被切断；
- 国内 CDN 同样普遍对长连接有超时限制，且默认开启响应缓冲。

处理方式：把 SSE 端点（`/api/v1/chat/**`、Agent 事件流）拆到独立子域
（如 `api.example.com`）**不走 CDN**（Cloudflare 设为灰云 / DNS only），
主站走 CDN 享受加速。

**2）nginx 必须关闭缓冲**

否则流式输出会被攒成一坨再一次性吐出，前端看起来像"卡住然后突然全出来"：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8000;
    proxy_buffering off;          # SSE 必须
    proxy_cache off;
    proxy_read_timeout 3600s;     # 长任务
    proxy_set_header Connection '';
    proxy_http_version 1.1;
}
```

## 4. 部署前检查

- [ ] **国内部署**：ICP 备案已通过，且备案后 30 日内完成公安备案
- [ ] `docker-compose.yml` 中所有镜像**已钉死版本**（本仓已用 digest 固定，不要改成 `latest`）
- [ ] 修改所有默认凭据：`POSTGRES_PASSWORD`、`MINIO_ROOT_USER/PASSWORD` 默认值仅供本地开发
- [ ] PostgreSQL、Redis、MinIO 的端口**不要暴露到公网**，只监听 `127.0.0.1` 或走内网
- [ ] `backend/.env` 配好至少一个 AI 供应商 Key，详见 [AI 大模型接入指南](ai-providers.md)
- [ ] `pnpm setup:search` 生成 SearXNG 密钥
- [ ] MinIO bucket 的 `avatars/*`、`files/*` 前缀权限按 [开发运行指南](dev-guide.md) 配置
- [ ] 配置数据库与对象存储的定期备份（PostgreSQL `pg_dump` + MinIO 同步到异地）
- [ ] 部署完成后按 [交付状态总表](master-plan.md) 确认仍未关闭的生产验收项

> 本项目的生产部署环境验收**尚未完成**（见 [master-plan.md](master-plan.md) §3）。
> 上线前请自行完成安全与容量验证，不要仅凭本地测试通过就放行。
