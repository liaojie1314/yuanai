## 一、设计理念

### 核心原则

1. **清透感**：主色调为淡蓝，背景微蓝白，整体清爽通透，不沉重
2. **内容优先**：对话内容是主角，UI 退居辅助，避免喧宾夺主
3. **无卡片化**：摒弃后台管理风格（无明显 border 卡片）——用背景色层次和留白区分区域，而非边框
4. **有活力**：适量动画让页面有生命感，包括背景微动、交互反馈、AI 打字效果
5. **克制圆角**：圆角统一 8px（输入框/按钮/气泡），强调精致而非夸张

### 设计风格参考

- 整体风格参考：Linear、Notion、Claude.ai（淡色、无卡片、干净）
- 颜色感受参考：Figma 新版（清透淡蓝）+ Tailwind CSS 官网
- **不要参考**：企业后台管理系统、Ant Design Pro 默认样式

### 动画规范

| 场景                   | 类型                                | 时长  | 缓动                        |
| ---------------------- | ----------------------------------- | ----- | --------------------------- |
| 按钮 hover 缩放        | `scale(1.02)`                       | 150ms | `ease-out`                  |

## 三、认证页面组

### 认证页公共背景（登录/注册/忘记密码共用）

**桌面端（宽屏 ≥ 1024px）：左右分栏布局**

```
┌──────────────────────┬──────────────────────┐
│                      │                      │
│   左侧装饰区（45%）  │   右侧表单区（55%）  │
│                      │                      │
│  背景：线性渐变       │  背景：#FFFFFF        │
│  from #1E40AF        │                      │
│  to   #3B82F6        │  表单内容居中         │
│                      │                      │
│  品牌 Logo + 口号    │                      │
│  浮动装饰图形        │                      │
│                      │                      │
└──────────────────────┴──────────────────────┘
```

**左侧装饰区设计要点**：

- 背景：`linear-gradient(145deg, #1E3A8A 0%, #1D4ED8 40%, #3B82F6 100%)`
- 顶部：品牌 Logo（白色「元」字 + 「yuanai」文字）
- 中部装饰（选其一）：
  - 方案 A：3-4 个对话气泡浮动动画，内容为 "你好" / "帮我写一段代码" / "解释一下量子纠缠" 等示意文字，气泡为半透明白色（`rgba(255,255,255,0.12)`），border `rgba(255,255,255,0.2)`
  - 方案 B：抽象几何图形（圆形、六边形轮廓），半透明白色线条，缓慢旋转或浮动
- 浮动动画：每个元素 y 轴 `-8px→8px` 来回浮动，各元素错开 0.5-1s 延迟，营造立体感
- 底部：3-4 条功能亮点文字（白色）例如「多模型支持 · GPT-4o · Claude · DeepSeek」
- 版权信息（弱化）：`rgba(255,255,255,0.4)`，12px

**移动端（< 1024px）：单栏，顶部带品牌色装饰**

```
┌────────────────────┐
│  品牌 Logo 区域    │  高度 200px
│  蓝色渐变背景      │  含浮动小图形
│  Logo + slogan    │
├────────────────────┤
│                    │
│  表单区域          │  圆角顶部 20px
│  白色背景          │  向上叠在渐变区
│                    │
└────────────────────┘
```

#### 表单校验规则

| 字段     | 规则                    | 错误提示（红色，12px，输入框下方 4px）      |
| -------- | ----------------------- | ------------------------------------------- |
| 邮箱     | 必填；符合 `email` 格式 | 「请输入正确的邮箱地址」                    |
| 密码     | 必填；最少 8 位         | 「密码不能为空」/ 「密码至少 8 位」         |
| 登录失败 | 后端返回 401            | 输入框变红边框 + 「邮箱或密码错误，请重试」 |

- 校验时机：字段 **失焦（onBlur）** 时触发，而非每次按键
- 成功态：登录按钮 loading 1.5s → 整页淡出 → 进入主界面（`opacity 0→1`，220ms）

### 3.3 忘记密码页 `/forgot-password`

**分为两个步骤（同一页面，内容切换动画 `translateX` 左右滑动）**

#### Step 1：发送验证码

```
标题：        「重置密码」，副标题「输入注册邮箱，我们将发送验证码」
步骤指示器：  两个圆点，当前步骤蓝色实心，下一步空心（简洁，不要步骤条）

邮箱输入框：  同登录页
发送按钮：    「发送验证码」，全宽，48px，蓝色主按钮
              发送后进入倒计时：「重新发送 (59s)」，按钮变次要态（灰色描边，不可点击）
              倒计时数字每秒更新，0 时恢复可点击

返回链接：    「← 返回登录」，13px，#3B82F6，位于按钮下方 16px
```

#### Step 2：验证码 + 新密码

```
标题：        「设置新密码」
副标题：      「验证码已发送至 user@exam**.com（脱敏显示）」

验证码输入框：
  - 6 个独立输入格（每格 48x56px，圆角 8px）
  - 边框 1px #BFDBFE，聚焦 #3B82F6 + 光晕
  - 每格只允许输入 1 位数字，输入后自动跳到下一格
  - 粘贴时自动填入全部格
  - 错误态：全部变红边框 + 抖动动画 + 「验证码错误」

新密码输入框：含强度指示器（同注册页）
确认密码输入框

「重置密码」按钮：全宽，蓝色主按钮

成功后：整页替换为成功状态
  - 绿色大勾（64px，动画从 0 scale 到 1，带弹性曲线 `cubic-bezier(0.34,1.56,0.64,1)`）
  - 「密码已重置」文字
  - 2s 后自动跳转登录页，或点击「立即登录」按钮
```

## 六、设计师注意事项

### 必须遵守

1. **禁止使用明显 border 的卡片**：内容区、侧边栏、消息区都不得出现白色圆角矩形 + 阴影的卡片（后台管理风）
2. **禁止使用纯灰色背景**（`#F5F5F5` 等）：所有背景必须带蓝色调
3. **圆角统一 8px**：不得出现 16px 以上的输入框/按钮圆角
4. **颜色不得使用蓝紫色**（`#6366F1`、`#7C3AED`）：本项目主色为纯蓝（`#3B82F6`）
5. **认证页背景不能留白**：左侧装饰区必须有浮动元素填充

### 推荐实践

1. 多使用**背景色差异**替代 border 来区分区域
2. 图标使用 **Lucide** 图标集，风格统一（线条图标，2px stroke）
3. 会话列表的 hover 状态用**过渡动画**（150ms），不要跳变
4. AI 消息区域尽量**舒展**，文字行高 26px，给阅读足够呼吸感
5. 按钮 hover 时轻微上浮（`translateY(-1px)`）增加交互感

### OpenDesign/Penpot 原型建议

1. 创建以下页面：Login / Register / ForgotPassword / Main-Empty / Main-Chat / Mobile-Chat
2. 为每个交互状态建立对应的 Frame（hover、focus、error、loading、success）
3. 使用 Penpot 的 **Components** 功能封装：Button、Input、Avatar、ModelSelector、ConversationItem、CodeBlock
4. 动画效果在 Penpot 中用 **Interactions** 功能标注（标注动画类型和时长即可，实现由开发负责）
5. 颜色统一用 **Library Colors** 管理，变量名与本文档的 CSS 变量名保持对应
